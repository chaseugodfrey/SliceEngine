Create Animations
=============================
Add animator ( Basic Controller will be assigned)
Drag or Create new Animation Package
If Created new, No animations inside click add animation
Click Save next to add Animation button to save the animation package


Adjust the frame line/ red arrow to choose the frame
Right click the position, rotation or scale to add key at current frame
Add events by clicking the  Add event button for the current frame
After every edit click Save next to add Animation button to save the animation and animation package



Create Controllers
==============================
After adding animator Basic Controller will be added 
Right click nodes and transitions to edit then click save as to save as new controller
then click the drop down to change the controller
States and animation need to have the same name in order to link them together
